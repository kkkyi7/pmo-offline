# 离线 PMO

给项目经理用的本机工具：项目计划 / 分阶段 WBS、大型甘特图、风险规则库。一份项目数据，一处改处处改。不调用任何在线模型。

## 怎么用

1. 安装 [Node.js](https://nodejs.org/)
2. 双击 `start.bat`
3. 浏览器打开后即可导入 Excel、改表、拖甘特、看风险

开发时：

```
npm install
npm run dev
npm test
```

## Excel 约定

标准工作簿按「项目实施主计划&WBS」结构划分工作表（Sheet）：

- `主计划`：一级阶段、二级场景、三级任务、前后置、状态、计划起止与计划天数、主责、交付物
- `*WBS`（各阶段分表，如 `项目准备WBS`、`需求分析WBS` 等）：二级场景、三级任务及活动分解、计划与实际起止、实际工作日、交付物。通过任务编号（如 `1.1.1`）与主计划双向联动
- `里程碑计划`：关键里程碑节点与评审要求
- `法定节假日`：国家法定放假调休日期表，用于自动跳过节假日推算工作日

内置模版位于 `templates/项目实施主计划&WBS-V0.7.xlsx`，应用内点击顶部「下载模版」也可随时导出空模版。

甘特图支持日/周/月视图，可直接拖拽调整计划起止，与主计划及阶段 WBS 表实时双向同步。

## 联动与规则（无 AI）

导入或改数之后，系统自动联动：
1. **工作日推期**：计划结束 = 计划开始 + 计划天数（跳过周末及法定节假日）
2. **前后置接力**：标记前后置关系的任务自动对接前序结束时间
3. **主计划 ↔ 阶段 WBS 双向对齐**：基于编号同步日期、天数与状态汇总
4. **风险规则扫描**：自动排查过期未完、工期倒挂、前置冲突、阶段未覆盖等潜在风险并直观呈现在甘特图上
